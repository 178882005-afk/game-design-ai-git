# Skills Glossary

This file gives short Chinese meanings for the common skills in this repo so they can be read and cited directly later.

## Routing and interview

- `Ask Matt`：帮你找到合适的 skill 或工作流。
- `PRD Rules`：约束 PRD 的问题定义、范围、状态、异常、依赖、验收和修订。
- `Grill with Docs`：通过采访梳理设计，并顺手把文档写出来。
- `Grill Me`：通过采访把方案想清楚。
- `Grilling`：一次围绕一组决策，逐轮压实思路。

## Planning and delivery

- `Wayfinder`：面对大而模糊的项目，先把决策地图摸清。
- `To Spec`：把想法整理成可执行规格。
- `To Tickets`：把规格拆成一张张任务票。
- `Implement`：按任务真正开始实现。
- `TDD`：用测试驱动的方式写功能。
- `Code Review`：按标准和规格检查改动。
- `Prototype`：先做个小原型验证想法。
- `Diagnosing Bugs`：定位并修复疑难 bug。
- `Handoff`：把任务交给另一个会话或 agent。
- `Claude Handoff`：把工作转交给后台 agent。

## Repository setup and maintenance

- `Setup Matt Pocock's Skills`：给仓库初始化这套技能约定。
- `Domain Modeling`：把领域术语和概念理清楚。
- `Codebase Design`：设计深层模块结构和边界。
- `Git Guardrails for Claude Code`：拦住危险的 git 操作。
- `Writing for Agents`：写给 agent 看的文档。
- `Wizard`：生成只能由人完成的操作流程。
- `Research`：做带引用的资料研究。
- `Resolving Merge Conflicts`：处理合并冲突。

## Other common skills

- `Triage`：把外部进来的问题分流到合适状态。
- `Improving Codebase Architecture`：找出值得加深和整理的架构机会。
