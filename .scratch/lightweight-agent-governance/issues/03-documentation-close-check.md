# 03 — 完成文档边界检查与交付收尾

**What to build:** 对治理文档和 PRD 规则执行最小化的边界与交付检查，确保入口可达、职责清晰、验收可执行。

**Blocked by:** 01 — 建立 Agent 通用治理入口；02 — 补充按需加载的 PRD 规则

**Status:** ready-for-agent

- [ ] Agent 入口指针能定位到治理文档，PRD 任务能定位到 PRD 规则。
- [ ] 文档不包含外部项目绝对路径、DreamGuard 内容、XML、数值表或代码规则。
- [ ] 普通任务不会被要求读取 PRD 专项规则或执行额外审批流程。
- [ ] 每项未解决依赖都有负责人或下一步动作。
- [ ] 文档检查和 Git 差异检查通过，且没有引入源代码、配置或运行时改动。
