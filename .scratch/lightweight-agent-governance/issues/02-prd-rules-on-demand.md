# 02 — 补充按需加载的 PRD 规则

**What to build:** 为 PRD 创建和重大修改建立独立的按需规则，减少重复描述，并让文档可以被实现和验收。

**Blocked by:** 01 — 建立 Agent 通用治理入口

**Status:** ready-for-agent

- [ ] PRD 只在创建或重大修改时加载本规则。
- [ ] 已确认范围只在范围与验收部分保留一份明确表述。
- [ ] MVP 部分只保留尚未决定是否做的内容、待定原因、影响和下一确认点。
- [ ] 有状态流程说明负责人、状态转换、异常处理和可观察结果。
- [ ] 需求修订不会把历史方案或未确认提案误写成当前规则。
