# 02 — 补充按需加载的 PRD 规则

**What to build:** 为 PRD 创建、修订和交付建立独立的按需规则，减少重复描述，并让文档可以被实现和验收。

**Blocked by:** 01 — 建立 Agent 通用治理入口

**Status:** ready

- [ ] PRD 创建、修订或交付时加载本规则。
- [ ] 已确认范围只在范围与验收部分保留一份明确表述。
- [ ] 正式正文只保留最终确定的需求；未决规则先在对话中询问用户，确认前不得生成或写入正式文档。
- [ ] 有状态流程说明负责人、状态转换、异常处理和可观察结果。
- [ ] 需求修订不会把历史方案或未确认提案误写成当前规则。
