# 01 — 建立 Agent 通用治理入口

**What to build:** 为 Agent 建立统一、轻量的任务处理主链路，覆盖任务分流、证据核对、必要决策、交付和收尾检查。

**Blocked by:** None — can start immediately.

**Status:** ready

- [ ] Agent 能按 `Route -> Evidence -> Decide -> Deliver -> Close` 处理非简单任务。
- [ ] 当前事实、历史内容、提案和待定项保持可区分。
- [ ] 只有现有资料无法确定的产品或范围选择才需要用户确认。
- [ ] 没有引入特定游戏、XML、数值表、代码规则或外部项目链路。
