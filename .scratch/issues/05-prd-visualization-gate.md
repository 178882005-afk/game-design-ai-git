# 05 — PRD 前置流程图与 UI 原型确认

**状态：** done

## 范围与来源

根据用户确认，将流程图和 UI 原型插入 PRD 正式生成之前，作为人工确认门槛。

## 已确定规则

- 流程图优先使用 Mermaid、SVG 或 HTML 等可编辑形式；图像生成模型用于视觉探索、风格稿和位图交付。
- UI 原型优先使用可交互 HTML；静态视觉稿可使用图像生成模型。
- 流程图和 UI 原型只表达已确认或明确标注待确认的内容，不能替代文字需求、配置或运行时证据。
- 人工确认流程、状态、界面区域和操作落点后，才允许生成或写入正式 PRD。
